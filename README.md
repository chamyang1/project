# MNIST 숫자 분류

MNIST 데이터셋을 활용해 손글씨 숫자를 분류하는 딥러닝 프로젝트입니다.

딥러닝의 기본적인 과정을 경험하고, 모델의 구조의 변화에 따라 성능이 어떻게 변화하는지 확인하는 것을 목표로 진행하였습니다.

## 사용한 데이터
### MNIST
* 손글씨 숫자 이미지 데이터셋
* 이미지 크기: 28 * 28
* 분류 대상: 숫자 0 ~ 9
* 학습 데이터: 60,000장
* 테스트 데이터: 10,000장

## 사용한 도구
  * Python
  * PyTorch
  * Google Colab
  * MNIST

## 모델
### 1. 기본 모델
처음에는 입력 이미지를 784개의 값으로 펼친 후 10개의 숫자로 바로 분류하는 모델을 사용했습니다.

28 x 28 → 784 → 10

모델의 테스트 결과 정확도는 89.09% 가 나왔습니다.

### 2. 개선 모델
정확도를 높이기 위해 중간에 128개의 뉴런을 가진 은닉층과 ReLU 활성화 함수를 추가했습니다.

28 x 28 → 784 → 128 → ReLU → 10

개선한 모델의 테스트 결과 정확도는 97.02% 가 나왔습니다.

## 결과
| 모델    | 구조                    | 테스트 정확도 |
| ----- | --------------------- | ------: |
| 기본 모델 | 784 → 10              |  89.09% |
| 개선 모델 | 784 → 128 → 10 + ReLU |  97.02% |

은닉층과 ReLU를 추가한 모델의 테스트 정확도가 더 높게 나오는 것을 확인했습니다.

## 학습 과정
이번 프로젝트에서는 다음과 같은 기본적인 딥러닝 학습 과정을 구현했습니다.

1. MNIST 데이터 불러오기

4. 신경망 모델 구성

8. 테스트 데이터를 이용한 정확도 측정
9. 모델 구조를 변경하여 결과 비교
